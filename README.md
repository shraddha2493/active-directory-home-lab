# active-directory-home-lab
Hands-on Windows Active Directory lab covering domain setup, user and group management, Group Policy, permissions, and troubleshooting using VMware.

## Project Overview
This project is a hands-on Windows administration lab designed to practice Active Directory concepts in a virtual environment using VMware.

## Objectives
- Understand Active Directory Domain Services (AD DS).
- Configure a Windows Server as a Domain Controller.
- Create and manage domain users and security groups.
- Organize users using Organizational Units (OUs).
- Practice password resets and account lockout troubleshooting.
- Configure shared folders and permissions.
- Explore Group Policy Objects (GPOs).
- Document troubleshooting steps and results.

## Lab Environment
- Virtualization: VMware Workstation
- Server operating system: To be documented
- Client operating system: Windows 10
- Directory service: Active Directory Domain Services
- Network configuration: NAT or another documented lab configuration

## Lab Activities
  - Prepare the Windows Server virtual machine.
  - Configure a static IP address.
  - Install Active Directory Domain Services.
  - Promote the server to a Domain Controller.
   - Create a test domain.
   - Create Organizational Units.
   - Create test users and security groups.
   - Join the Windows client to the domain.
   - Practice password reset and account unlock.
   - Configure shared-folder permissions.
   - Create and test a Group Policy.
   - Document troubleshooting scenarios.

## Troubleshooting Documentation
Each scenario will include:
1. Problem description
2. Symptoms
3. Diagnostic commands or tools
4. Root cause
5. Resolution
6. Verification
